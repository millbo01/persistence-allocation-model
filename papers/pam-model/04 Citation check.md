# Citation check for draft 1 (7 October 2026)

**Method:**
- **Bibliographic details:** each reference checked against Crossref, PubMed or OpenAlex (authors, year, title, journal, volume, pages, DOI).
- **Attributed claims:** each claim the draft attributes to a source checked against what was read. The "Read" column says how much of the source was read.

**Result:** 33 references checked (32 in the main text, 1 in S1): 32 verified, and Krieger (1921) cited only second-hand, as stated. **Eleven corrections made** (listed below). No unverified reference remains in the main text or S1.
